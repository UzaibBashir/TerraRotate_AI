# Data sources

The official Field Shift Resources tab was inspected on 14 Nov 2026. Its complete 24-card inventory and provider classification are recorded in `docs/nasa_resource_allowlist.md`. The resources tab offers optional materials; it does not require integrating all 24. This source register distinguishes resources actually used from suggestions reviewed.

| Source | Type | Use | Resolution and limitations | Status |
|---|---|---|---|---|
| NASA POWER Daily Point API | NASA meteorology / solar / hydrology estimates | T2M, PRECTOTCORR, plus water-module PRECTOTCORR, SFMC, RZMC, and EVPTRNS | Product/grid varies by parameter; nearest source cell; some parameters may be missing at a point | Live connectors; hydrology request verified 14 Nov 2026. Evapotranspiration parameter is energy flux and is not converted to water depth. |
| NASA POWER Monthly Point API | NASA meteorology estimates | Historical monthly T2M and PRECTOTCORR for field and candidate climate profiles | Parameter-specific source grids; monthly regional climate context | Climate analog module fetches a user-chosen point and up to five candidate points for one common historical period. |
| NASA POWER Projection API | NASA NEX-GDDP-CMIP6 multi-model ensemble exposed by POWER | Monthly T2M and PRECTOTCORR for SSP1-2.6, SSP2-4.5, SSP3-7.0 | ~0.25° global grid, nearest cell without interpolation; 2015–2100; not a farm forecast | Live endpoint returned HTTP 200 for the illustrative Kashmir point, but all selected 2041–2060 values were missing sentinels. Missing values now remain null with coverage counts. |
| NASA GIBS WMS imagery | NASA EOSDIS visualizations sourced from listed SMAP, GPM/IMERG, MODIS and VIIRS observations | SMAP L4 analyzed surface-soil-moisture map; daily IMERG precipitation-rate map; Terra MODIS 8-day NDVI; MODIS Terra/Aqua and SNPP VIIRS true color; official legend when advertised by WMS capabilities | Source products have different grids and revisit periods; rendered images are contextual visualizations and are not converted into field values. A supplied field boundary is an overlay only. | Backend image and capabilities-based legend proxy; point selection and 1×–4× zoom; five dated global browse samples downloaded to `data/resource_samples/` on 14 Nov 2026 |
| Farmer-entered field values | User input | Coordinates, current crop, water availability, priorities | Accuracy is user-dependent | Used per request; not persisted |
| Crop catalog | Curated broad characteristics | Crop duration, family, water class, season, legume classification | Regional and cultivar variation; see `docs/crop_catalog.md` | Prototype baseline |

SMAP and GPM/IMERG are connected through GIBS visualization layers. Their source-data values and the MODIS NDVI value are not extracted from those images, passed into the rotation engine, or represented as field readings. The vegetation and bare-window analytical modules accept dated numeric observations with source and resolution supplied by the user; they do not decode GIBS colors. NASA POWER/GIBS successful responses use bounded process-local TTL caches. Landsat, SRTM, ECOSTRESS, GLDAS, and GEDI remain listed but not integrated. For a global version, FAO GAEZ, and the listed ESA Sentinel-2 / ECMWF ERA5 partner resources are potential candidates, but are not currently used. U.S.-only and North America-only products should be enabled conditionally by location, never presented as global coverage. Soil values remain farmer-entered only.
