# Requirements and scientific constraints

TerraRotate helps farmers explore rotation strategies using NASA Earth observations, locally supplied soil/context, crop characteristics, and farmer priorities. It should explain evidence and information gaps, support rather than replace farmer judgment, allow location selection, and identify sources and limits.

The indexed official challenge statement was reviewed. Direct access to its Resources tab failed during initial research; a public event mirror lists the suggested datasets. NASA POWER was selected because it is on that mirror and NASA's official service documentation/API were reachable. See the allowlist's caveat. No second data connector should be added until confirmed against the official tab.

Scientific constraints: no vegetation diagnosis in this increment; gridded climate values are not field-sensor readings; soil is user supplied; crop entries are broad baselines; rotation scores are not validated agronomic conclusions; missing observations stay missing.
